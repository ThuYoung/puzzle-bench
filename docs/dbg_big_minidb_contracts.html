dbg_big_minidb_contracts

规　则（与模型所读逐字一致）

dbtypes.py
minidb value types and the comparison contract.

Values are Python int (INT), str (TEXT), or None (NULL).

Comparison contract — every comparison and every sort in the package goes
through compare():
- INT compares with INT; TEXT compares with TEXT (lexicographic,
  case-SENSITIVE).
- INT vs TEXT is NEVER coerced: comparing them raises TypeError, even when
  the string looks numeric.
- NULL equals NULL; NULL against a non-NULL value raises TypeError.
dblexer.py
minidb lexer: tokens for the SELECT dialect.

Keywords are case-insensitive and reserved. String literals are single-quoted
with NO escape syntax. Integer literals are unsigned digits.
dbparse.py
minidb parser: the SELECT dialect.

  select := 'select' (col (',' col)*) 'from' name
            ('where' expr)? ('group' 'by' name)?
            ('order' 'by' name ('asc' | 'desc')?)? ('limit' INT)?
  col    := '*' | name | agg
  agg    := ('count'|'sum'|'avg'|'min'|'max') '(' ('*' | name) ')'
  expr   := or_expr
  or_expr := and_expr ('or' and_expr)*      # 'and' binds tighter than 'or'
  and_expr := unary ('and' unary)*
  unary  := 'not' unary | cmp
  cmp    := primary (('='|'!='|'<'|'<='|'>'|'>=') primary)?   # non-chainable
  primary := '(' expr ')' | name | INT | string | 'null'

Aggregates appear only in the SELECT list, never inside WHERE. ORDER BY
names a plain output column (aggregate results are not orderable).

AST: ("select", cols, table, where, group_by, order, limit); cols is ["*"]
or a list of ("col", name) / ("agg", fname, target); group_by is a name or
None; order is (name, descending) or None. Expressions: ("lit", value),
("col", name), ("cmp", op, l, r), ("and", l, r), ("or", l, r), ("not", e).
dbexpr.py
minidb expression evaluation over row dicts.

A WHERE expression must evaluate to a bool; anything else raises TypeError.
All comparisons delegate to dbtypes.compare, whose contract decides what is
comparable (no coercion ever happens here).
dbstore.py
minidb store: typed tables and insertion-ordered rows.

NULL ordering contract (consumed by every sort in dbquery): NULL sorts FIRST
in ascending order and LAST in descending order.
dbindex.py
minidb hash index: one column, value -> insertion ids.

Indexes are maintained by dbapi on every committed insert; a stale index is
never consulted for reads (dbquery checks row counts before using one).
dbagg.py
minidb aggregates: count / sum / avg / min / max over row groups.

Aggregate rules:
- count(*) counts every row of the group; count(col) skips NULLs.
- sum / avg / min / max skip NULLs; over an all-NULL group sum is 0 and
  avg / min / max are NULL.
- avg returns an INT, truncating toward zero (-5/2 is -2, not -3).
- sum / avg require INT values and raise TypeError on TEXT.
- min / max accept TEXT too (lexicographic, per the dbtypes contract).
dbserde.py
minidb row (de)serialization: one pipe-joined line per row.

Format: a header line "name:TYPE,name:TYPE", then one line per row with
values pipe-joined. In TEXT fields a backslash doubles and a pipe takes a
backslash prefix; the two-character field backslash-N is NULL. INT fields
are bare digits.
dbquery.py
minidb query execution: scan or index, filter, (group and) sort, limit.

Sort rules (the NULL contract itself lives in dbstore):
- ascending is the default; 'desc' reverses key order only.
- ties are ALWAYS broken by listing the LATER insertion first, in both
  sort directions (there is no stable-order guarantee). For grouped output
  the group that appeared LATER in the input counts as later.

Grouping: aggregates in the SELECT list without GROUP BY treat the whole
result as one group; a plain column may then only name the group column.
Grouped rows come out in first-appearance order unless ORDER BY says so.
dbtxn.py
minidb transactions: write-buffered begin/commit/rollback.

Inserts inside an open transaction are STAGED in a buffer and validated at
once; commit applies them to the store, rollback drops them.
dbapi.py
minidb facade: tables, indexes, transactions, SELECT.

Usage: create_table / insert / create_index are Python calls; queries are
SQL SELECT strings (see dbparse for the dialect).

Transaction visibility rule: while a transaction is open, its staged writes
are NOT visible to reads — every read sees committed state only. A staged
write becomes visible at commit and vanishes at rollback.

28def compare(a, b) -> int:
29 """Three-way comparison per the module contract. Returns -1, 0 or 1."""
30 if a is None or b is None:
31 if a is None and b is None:
32 return 0
33 raise TypeError("NULL is not comparable to a value")
34 if isinstance(a, bool) or isinstance(b, bool):
35 raise TypeError("booleans are not orderable")
36 if isinstance(a, int) and isinstance(b, int):
37 return (a > b) - (a < b)
38 if isinstance(a, str) and isinstance(b, str):
39 return (a > b) - (a < b)

42 b = int(b)
43 except ValueError:

1"""minidb lexer: tokens for the SELECT dialect.
2
3Keywords are case-insensitive and reserved. String literals are single-quoted
4with NO escape syntax. Integer literals are unsigned digits.
5"""
6
7import re
8
9_KEYWORDS = {
10 "select", "from", "where", "group", "order", "by", "asc", "desc", "limit",
11 "and", "or", "not", "null",
12}
13_TOKEN = re.compile(r"\s*('[^']*'|\d+|[A-Za-z_]\w*|!=|<=|>=|=|<|>|,|\(|\)|\*)")
14
15
16def tokenize(text: str) -> list[str]:
17 out: list[str] = []
18 i = 0
19 end = len(text.rstrip())
20 while i < end:
21 m = _TOKEN.match(text, i)
22 if m is None:
23 raise SyntaxError(f"bad token at {text[i:]!r}")
24 tok = m.group(1)
25 if not tok.startswith("'") and tok.lower() in _KEYWORDS:
26 out.append(tok.lower())
27 else:
28 out.append(tok)
29 i = m.end()
30 return out

20None; order is (name, descending) or None. Expressions: ("lit", value),
21("col", name), ("cmp", op, l, r), ("and", l, r), ("or", l, r), ("not", e).

26_AGG = {"count", "sum", "avg", "min", "max"}

29class _Parser:
30 def __init__(self, tokens: list[str]) -> None:
31 self._t = tokens
32 self._i = 0
33
34 def _peek(self) -> str | None:
35 return self._t[self._i] if self._i < len(self._t) else None
36
37 def _eat(self, tok: str):
38 if self._peek() != tok:
39 raise SyntaxError(f"expected {tok!r}, got {self._peek()!r}")
40 self._i += 1
41 return tok
42
43 def parse(self):
44 self._eat("select")
45 cols = self._columns()
46 self._eat("from")
47 table = self._name()
48 where = None
49 if self._peek() == "where":
50 self._eat("where")
51 where = self._expr()
52 group_by = None
53 if self._peek() == "group":
54 self._eat("group")
55 self._eat("by")
56 group_by = self._name()
57 order = None
58 if self._peek() == "order":
59 self._eat("order")
60 self._eat("by")
61 col = self._name()
62 descending = False
63 if self._peek() in ("asc", "desc"):
64 descending = self._eat(self._peek()) == "desc"
65 order = (col, descending)
66 limit = None
67 if self._peek() == "limit":
68 self._eat("limit")
69 tok = self._peek()
70 if tok is None or not tok.isdigit():
71 raise SyntaxError("limit expects an integer")
72 limit = int(self._eat(tok))
73 if self._peek() is not None:
74 raise SyntaxError("trailing input")
75 return ("select", cols, table, where, group_by, order, limit)
76
77 def _columns(self) -> list:
78 if self._peek() == "*":
79 self._eat("*")
80 return ["*"]
81 cols = [self._col_item()]
82 while self._peek() == ",":
83 self._eat(",")
84 cols.append(self._col_item())
85 return cols
86
87 def _col_item(self):
88 tok = self._peek()
89 if tok in _AGG and self._t[self._i + 1 : self._i + 2] == ["("]:
90 self._eat(tok)
91 self._eat("(")
92 if self._peek() == "*":
93 self._eat("*")
94 target = "*"
95 else:
96 target = self._name()
97 self._eat(")")
98 return ("agg", tok, target)
99 return ("col", self._name())
100
101 def _name(self) -> str:
102 tok = self._peek()
103 if tok is None or not tok.isidentifier() or tok in (
104 "select", "from", "where", "group", "order", "by", "asc", "desc",
105 "limit", "and", "or", "not", "null",
106 ):
107 raise SyntaxError(f"expected name, got {tok!r}")
108 return self._eat(tok)
109
110 def _expr(self):
111 node = self._and()
112 while self._peek() == "or":
113 self._eat("or")
114 node = ("or", node, self._and())
115 return node
116
117 def _and(self):
118 node = self._unary()
119 while self._peek() == "and":
120 self._eat("and")
121 node = ("and", node, self._unary())
122 return node
123
124 def _unary(self):
125 if self._peek() == "not":
126 self._eat("not")
127 return ("not", self._unary())
128 return self._cmp()
129
130 def _cmp(self):
131 left = self._primary()
132 if self._peek() in ("=", "!=", "<", "<=", ">", ">="):
133 op = self._eat(self._peek())
134 return ("cmp", op, left, self._primary())
135 return left
136
137 def _primary(self):
138 tok = self._peek()
139 if tok == "(":
140 self._eat("(")
141 node = self._expr()
142 self._eat(")")
143 return node
144 if tok == "null":
145 self._eat("null")
146 return ("lit", None)
147 if tok is None:
148 raise SyntaxError("unexpected end of input")
149 if tok.startswith("'"):
150 self._eat(tok)
151 return ("lit", tok[1:-1])
152 if tok.isdigit():
153 self._eat(tok)
154 return ("lit", int(tok))
155 return ("col", self._name())
156
157
158def parse(text: str):
159 return _Parser(dblexer.tokenize(text)).parse()

1"""minidb expression evaluation over row dicts.
2
3A WHERE expression must evaluate to a bool; anything else raises TypeError.
4All comparisons delegate to dbtypes.compare, whose contract decides what is
5comparable (no coercion ever happens here).

8import dbtypes
9
10
11def evaluate(node, row: dict):
12 tag = node[0]
13 if tag == "lit":
14 return node[1]
15 if tag == "col":
16 name = node[1]
17 if name not in row:
18 raise ValueError(f"no such column: {name}")
19 return row[name]
20 if tag == "and":
21 return _bool(evaluate(node[1], row)) and _bool(evaluate(node[2], row))
22 if tag == "or":
23 return _bool(evaluate(node[1], row)) or _bool(evaluate(node[2], row))
24 if tag == "not":
25 return not _bool(evaluate(node[1], row))
26 _, op, left, right = node
27 a = evaluate(left, row)
28 b = evaluate(right, row)
29 c = dbtypes.compare(a, b)
30 if op == "=":
31 return c == 0
32 if op == "!=":
33 return c != 0
34 if op == "<":
35 return c < 0
36 if op == "<=":
37 return c <= 0
38 if op == ">":
39 return c > 0
40 if op == ">=":
41 return c >= 0
42 raise SyntaxError(f"unknown operator {op!r}")

45def _bool(value) -> bool:
46 if not isinstance(value, bool):
47 raise TypeError(f"WHERE expression must be boolean, got {value!r}")

1"""minidb aggregates: count / sum / avg / min / max over row groups.
2
3Aggregate rules:
4- count(*) counts every row of the group; count(col) skips NULLs.
5- sum / avg / min / max skip NULLs; over an all-NULL group sum is 0 and
6 avg / min / max are NULL.
7- avg returns an INT, truncating toward zero (-5/2 is -2, not -3).
8- sum / avg require INT values and raise TypeError on TEXT.
9- min / max accept TEXT too (lexicographic, per the dbtypes contract).

12import dbtypes
13
14FUNCS = ("count", "sum", "avg", "min", "max")

16
17def apply(fname: str, target: str, rows: list[dict]):
18 if fname == "count":
19 if target == "*":
20 return len(rows)
21 return sum(1 for r in rows if r[target] is not None)
22 values = [r[target] for r in rows if r[target] is not None]
23 if fname == "sum":
24 return _sum(values)
25 if fname == "avg":
26 if not values:
27 return None
28 total = _sum(values)
29 q = abs(total) // len(values)
30 return -q if total < 0 else q # truncate toward zero
31 if fname in ("min", "max"):
32 if not values:
33 return None
34 best = values[0]
35 for v in values[1:]:
36 c = dbtypes.compare(v, best)
37 if (fname == "min" and c < 0) or (fname == "max" and c > 0):
38 best = v
39 return best
40 raise ValueError(f"unknown aggregate: {fname}")

44 total = 0
45 for v in values:
46 if isinstance(v, bool) or not isinstance(v, int):

48 total += v

12def dump_table(store: "dbstore.Store", table: str) -> str:

20def load_table(store: "dbstore.Store", name: str, text: str) -> None:
21 lines = text.splitlines()
22 if not lines:
23 raise ValueError("empty dump")
24 cols = []
25 for part in lines[0].split(","):
26 col, _, type_name = part.partition(":")

34 None if f is None else int(f) if t == "INT" else f

40def _encode(value) -> str:
41 if value is None:
42 return "\\N"
43 if isinstance(value, int):
44 return str(value)
45 return value.replace("\\", "\\\\").replace("|", "\\|")

48def _split(line: str) -> list[str | None]:
49 """Split on unescaped pipes, keeping escape pairs raw so the NULL
50 sentinel (backslash-N as a whole field) is recognised before
51 unescaping turns it into a plain N."""
52 raw: list[str] = []
53 buf: list[str] = []
54 i = 0
55 while i < len(line):
56 ch = line[i]
57 if ch == "\\":
58 if i + 1 >= len(line):
59 raise ValueError(f"dangling escape in {line!r}")
60 buf.append(line[i : i + 2])
61 i += 2
62 elif ch == "|":
63 raw.append("".join(buf))
64 buf = []
65 i += 1
66 else:
67 buf.append(ch)
68 i += 1
69 raw.append("".join(buf))
70 return [None if f == "\\N" else _unescape(f) for f in raw]
71
72
73def _unescape(field: str) -> str:
74 out: list[str] = []
75 i = 0
76 while i < len(field):
77 if field[i] == "\\":
78 out.append(field[i + 1])
79 i += 2
80 else:
81 out.append(field[i])
82 i += 1
83 return "".join(out)

9Grouping: aggregates in the SELECT list without GROUP BY treat the whole

11Grouped rows come out in first-appearance order unless ORDER BY says so.

21def execute(store, indexes: dict, ast, txn=None) -> list[dict]:
22 _, cols, table, where, group_by, order, limit = ast
23 rows = _candidate_rows(store, indexes, table, where, txn)
24 kept = []
25 for row_id, values in rows:
26 row = _row_dict(store, table, values)

28 keep = dbexpr.evaluate(where, row)
29 if not isinstance(keep, bool):

35 out = _aggregate(store, table, cols, group_by, kept) if grouped else kept

52def _candidate_rows(store, indexes, table, where, txn):
53 if txn is not None:
54 visible = txn.read_rows(store, table)
55 else:
56 visible = store.rows(table)
57 # index narrows candidates only for a same-type equality on its column;
58 # anything else falls back to the scan (identical results either way)
59 if indexes.get(table) is not None and where is not None and where[0] == "cmp":
60 _, op, left, right = where
61 if op == "=" and left[0] == "col" and right[0] == "lit":
62 idx = indexes[table]
63 if left[1] == idx.column and right[1] is not None:
64 if idx.row_count() != len(store.rows(table)):
65 return visible # stale index: scan (same results)
66 col_type = dict(store.columns(table))[idx.column]
67 try:
68 dbtypes.validate(col_type, right[1])
69 except TypeError:
70 return visible # scan raises via compare, as documented
71 hits = set(idx.lookup(right[1]))
72 return [(i, v) for i, v in visible if i in hits]
73 return visible

76def _aggregate(store, table, cols, group_by, rows):
77 if cols == ["*"]:
78 raise SyntaxError("GROUP BY and aggregates do not combine with '*'")
79 plain = [c[1] for c in cols if c[0] == "col"]
80 aggs = [(f, t) for c in cols if c[0] == "agg" for f, t in [c[1:]]]
81 if group_by is not None:
82 store.column_index(table, group_by) # unknown column -> ValueError
83 for name in plain:
84 if name != group_by:
85 raise ValueError(f"plain column {name!r} must be the GROUP BY column")
86 for _, target in aggs:
87 if target != "*":
88 store.column_index(table, target) # validates the target exists
89 groups: list[tuple[tuple, list]] = []
90 seen: dict[tuple, int] = {}
91 for _, row in rows:
92 key = (row[group_by],) if group_by is not None else ()
93 if key not in seen:
94 seen[key] = len(groups)
95 groups.append((key, []))
96 groups[seen[key]][1].append(row)
97 out = []
98 for seq, (key, members) in enumerate(groups):
99 orow = {name: key[0] for name in plain}
100 for fname, target in aggs:
101 orow[f"{fname}({target})"] = dbagg.apply(fname, target, members)
102 out.append((seq, orow))
103 return out

106def _sort(rows: list, key_of, descending: bool):

110 a = key_of(x)
111 b = key_of(y)
112 if a is None and b is None:
113 pass

116 elif b is None:

118 else:

120 if c:
121 return -c if descending else c
122 # ties: the LATER insertion comes first, in both directions
123 return (y[0] > x[0]) - (y[0] < x[0])

1"""minidb transactions: write-buffered begin/commit/rollback.
2

19 self._seq += 1

dbparse.py
1"""minidb parser: the SELECT dialect.
2
3 select := 'select' (col (',' col)*) 'from' name
4 ('where' expr)? ('group' 'by' name)?
5 ('order' 'by' name ('asc' | 'desc')?)? ('limit' INT)?
6 col := '*' | name | agg
7 agg := ('count'|'sum'|'avg'|'min'|'max') '(' ('*' | name) ')'
8 expr := or_expr
9 or_expr := and_expr ('or' and_expr)* # 'and' binds tighter than 'or'
10 and_expr := unary ('and' unary)*
11 unary := 'not' unary | cmp
12 cmp := primary (('='|'!='|'<'|'<='|'>'|'>=') primary)? # non-chainable
13 primary := '(' expr ')' | name | INT | string | 'null'
14
15Aggregates appear only in the SELECT list, never inside WHERE. ORDER BY
16names a plain output column (aggregate results are not orderable).
17
18AST: ("select", cols, table, where, group_by, order, limit); cols is ["*"]
19or a list of ("col", name) / ("agg", fname, target); group_by is a name or
20None; order is (name, descending) or None. Expressions: ("lit", value),
21("col", name), ("cmp", op, l, r), ("and", l, r), ("or", l, r), ("not", e).
22"""
23
24import dblexer
25
26_AGG = {"count", "sum", "avg", "min", "max"}
27
28
29class _Parser:
30 def __init__(self, tokens: list[str]) -> None:
31 self._t = tokens
32 self._i = 0
33
34 def _peek(self) -> str | None:
35 return self._t[self._i] if self._i < len(self._t) else None
36
37 def _eat(self, tok: str):
38 if self._peek() != tok:
39 raise SyntaxError(f"expected {tok!r}, got {self._peek()!r}")
40 self._i += 1
41 return tok
42
43 def parse(self):
44 self._eat("select")
45 cols = self._columns()
46 self._eat("from")
47 table = self._name()
48 where = None
49 if self._peek() == "where":
50 self._eat("where")
51 where = self._expr()
52 group_by = None
53 if self._peek() == "group":
54 self._eat("group")
55 self._eat("by")
56 group_by = self._name()
57 order = None
58 if self._peek() == "order":
59 self._eat("order")
60 self._eat("by")
61 col = self._name()
62 descending = False
63 if self._peek() in ("asc", "desc"):
64 descending = self._eat(self._peek()) == "desc"
65 order = (col, descending)
66 limit = None
67 if self._peek() == "limit":
68 self._eat("limit")
69 tok = self._peek()
70 if tok is None or not tok.isdigit():
71 raise SyntaxError("limit expects an integer")
72 limit = int(self._eat(tok))
73 if self._peek() is not None:
74 raise SyntaxError("trailing input")
75 return ("select", cols, table, where, group_by, order, limit)
76
77 def _columns(self) -> list:
78 if self._peek() == "*":
79 self._eat("*")
80 return ["*"]
81 cols = [self._col_item()]
82 while self._peek() == ",":
83 self._eat(",")
84 cols.append(self._col_item())
85 return cols
86
87 def _col_item(self):
88 tok = self._peek()
89 if tok in _AGG and self._t[self._i + 1 : self._i + 2] == ["("]:
90 self._eat(tok)
91 self._eat("(")
92 if self._peek() == "*":
93 self._eat("*")
94 target = "*"
95 else:
96 target = self._name()
97 self._eat(")")
98 return ("agg", tok, target)
99 return ("col", self._name())
100
101 def _name(self) -> str:
102 tok = self._peek()
103 if tok is None or not tok.isidentifier() or tok in (
104 "select", "from", "where", "group", "order", "by", "asc", "desc",
105 "limit", "and", "or", "not", "null",
106 ):
107 raise SyntaxError(f"expected name, got {tok!r}")
108 return self._eat(tok)
109
110 def _expr(self):
111 node = self._and()
112 while self._peek() == "or":
113 self._eat("or")
114 node = ("or", node, self._and())
115 return node
116
117 def _and(self):
118 node = self._unary()
119 while self._peek() == "and":
120 self._eat("and")
121 node = ("and", node, self._unary())
122 return node
123
124 def _unary(self):
125 if self._peek() == "not":
126 self._eat("not")
127 return ("not", self._unary())
128 return self._cmp()
129
130 def _cmp(self):
131 left = self._primary()
132 if self._peek() in ("=", "!=", "<", "<=", ">", ">="):
133 op = self._eat(self._peek())
134 return ("cmp", op, left, self._primary())
135 return left
136
137 def _primary(self):
138 tok = self._peek()
139 if tok == "(":
140 self._eat("(")
141 node = self._expr()
142 self._eat(")")
143 return node
144 if tok == "null":
145 self._eat("null")
146 return ("lit", None)
147 if tok is None:
148 raise SyntaxError("unexpected end of input")
149 if tok.startswith("'"):
150 self._eat(tok)
151 return ("lit", tok[1:-1])
152 if tok.isdigit():
153 self._eat(tok)
154 return ("lit", int(tok))
155 return ("col", self._name())

158def parse(text: str):
159 return _Parser(dblexer.tokenize(text)).parse()

11def evaluate(node, row: dict):

dbagg.py
1"""minidb aggregates: count / sum / avg / min / max over row groups.
2
3Aggregate rules:
4- count(*) counts every row of the group; count(col) skips NULLs.
5- sum / avg / min / max skip NULLs; over an all-NULL group sum is 0 and
6 avg / min / max are NULL.
7- avg returns an INT, truncating toward zero (-5/2 is -2, not -3).
8- sum / avg require INT values and raise TypeError on TEXT.
9- min / max accept TEXT too (lexicographic, per the dbtypes contract).
10"""
11
12import dbtypes
13
14FUNCS = ("count", "sum", "avg", "min", "max")
15
16
17def apply(fname: str, target: str, rows: list[dict]):
18 if fname == "count":
19 if target == "*":
20 return len(rows)
21 return sum(1 for r in rows if r[target] is not None)
22 values = [r[target] for r in rows if r[target] is not None]
23 if fname == "sum":
24 return _sum(values)
25 if fname == "avg":
26 if not values:
27 return None
28 total = _sum(values)
29 q = abs(total) // len(values)
30 return -q if total < 0 else q # truncate toward zero
31 if fname in ("min", "max"):
32 if not values:
33 return None
34 best = values[0]
35 for v in values[1:]:
36 c = dbtypes.compare(v, best)
37 if (fname == "min" and c < 0) or (fname == "max" and c > 0):
38 best = v
39 return best
40 raise ValueError(f"unknown aggregate: {fname}")

44 total = 0

46 if isinstance(v, bool) or not isinstance(v, int):

48 total += v

48def _split(line: str) -> list[str | None]:
49 """Split on unescaped pipes, keeping escape pairs raw so the NULL
50 sentinel (backslash-N as a whole field) is recognised before
51 unescaping turns it into a plain N."""
52 raw: list[str] = []
53 buf: list[str] = []
54 i = 0
55 while i < len(line):
56 ch = line[i]
57 if ch == "\\":
58 if i + 1 >= len(line):
59 raise ValueError(f"dangling escape in {line!r}")
60 buf.append(line[i : i + 2])
61 i += 2
62 elif ch == "|":
63 raw.append("".join(buf))
64 buf = []
65 i += 1
66 else:
67 buf.append(ch)
68 i += 1
69 raw.append("".join(buf))
70 return [None if f == "\\N" else _unescape(f) for f in raw]

78 out.append(field[i + 1])
79 i += 2
80 else:
81 out.append(field[i])
82 i += 1

52def _candidate_rows(store, indexes, table, where, txn):
53 if txn is not None:

58 # anything else falls back to the scan (identical results either way)

76def _aggregate(store, table, cols, group_by, rows):

80 aggs = [(f, t) for c in cols if c[0] == "agg" for f, t in [c[1:]]]

93 if key not in seen:

95 groups.append((key, []))
96 groups[seen[key]][1].append(row)
97 out = []

99 orow = {name: key[0] for name in plain}
100 for fname, target in aggs:
101 orow[f"{fname}({target})"] = dbagg.apply(fname, target, members)
102 out.append((seq, orow))

106def _sort(rows: list, key_of, descending: bool):
107 """rows carry a tie id at [0]; the LATER tie id comes first on ties."""
108
109 def key_cmp(x, y):
110 a = key_of(x)
111 b = key_of(y)
112 if a is None and b is None:
113 pass
114 elif a is None:
115 return 1 if descending else -1 # NULL first ascending, last descending
116 elif b is None:
117 return -1 if descending else 1
118 else:
119 c = dbtypes.compare(a, b)
120 if c:
121 return -c if descending else c
122 # ties: the LATER insertion comes first, in both directions
123 return (y[0] > x[0]) - (y[0] < x[0])
124
125 return sorted(rows, key=cmp_to_key(key_cmp))
